# 上傳到 GitHub 指南

## 🌐 網頁上傳步驟：

1. 前往：https://github.com/nicky891023-wq/AQI_analysis
2. 點擊 "Add file" → "Upload files"
3. 拖拽這些檔案：
   - aqi_map.py (主程式)
   - test_aqi_map.py (測試版本)
   - requirements.txt (依賴套件)
   - README.md (說明文件)
   - .gitignore (Git 忽略檔案)
   - setup_git.bat (Git 設定)
   - upload_to_github.bat (上傳腳本)

4. 提交訊息：`Initial commit: AQI Analysis Project`
5. 點擊 "Commit changes"

## 📁 注意事項：
- 不要上傳 .env 檔案（包含 API 金鑰）
- 在 GitHub 上建立 .env 檔案範例
- 記得在 README 中說明如何設定環境變數

## 🚀 完成後你的專案就會在：
https://github.com/nicky891023-wq/AQI_analysis
