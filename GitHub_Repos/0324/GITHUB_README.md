# 🎯 ARIA v3.0 - 動態風險監測系統

**Week 5: 遙測與空間資訊之分析與應用 - 動態風險監測系統**

## 📋 專案概述

ARIA v3.0 是一個全自動區域受災衝擊評估系統，能夠回答「**現在哪裡最危險？**」的關鍵問題。系統整合了即時雨量監測、地形風險評估與避難所空間分析，提供完整的災害監測決策支援。

## 🚀 系統特色

### 核心功能
- 🌧️ **即時雨量監測** - CWA API整合與Fallback機制
- 🎯 **動態風險評估** - 四級風險分類系統 (CRITICAL/URGENT/WARNING/SAFE)
- 🗺️ **空間疊合分析** - 5km雨量影響範圍與避難所疊合
- 📊 **互動式視覺化** - Folium動態地圖與豐富資訊展示
- 🔄 **模式切換** - LIVE即時模式與SIMULATION模擬模式

### 技術實現
- 📍 **坐標系統管理** - EPSG:4326與EPSG:3826正確轉換
- ⚡ **效能最佳化** - 向量化操作與記憶體管理
- 🛡️ **錯誤處理** - 完整的異常處理與日誌記錄
- 🏗️ **模組化設計** - 清晰的函數分工與系統架構

```bash

# 2. 安裝Conda環境

```

### 動態風險分級
| 風險等級 | 條件 | 顏色 | 意義 |
|---------|------|------|------|
| 🚨 CRITICAL | 時雨量 > 80mm | 深紅色 | 極端危險 |
| ⚠️ URGENT | 時雨量 > 40mm 且地形HIGH | 紅色 | 緊急危險 |
| ⚡ WARNING | 時雨量 > 40mm 或地形HIGH | 橙色 | 警告狀態 |
